description: Build one small slice of the current phase, test-first
---

1. Read `docs/PLAN.md` and name the phase and the gate this slice moves towards.
2. Write a plan Artifact: files to add or change, tests to write. Wait for approval.
3. Write the failing tests first.
4. Implement until the tests pass.
5. Run the `/check` workflow.
6. Commit with a message saying what changed and why.
